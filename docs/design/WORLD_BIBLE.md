# 《绒火与月铃》世界圣经

## 一句话

月铃山谷依靠月铃塔维持记忆、天气与居民关系的平衡。月铃失声后，见习守铃者绒火必须用行动而不是空洞许愿，重新让山谷共鸣。

## 地理

- 月铃聚落：商店、工坊、旅店和月铃塔入口所在的枢纽。
- 绒火森林：树脂、桥梁和基础战斗教学区域。
- 月露河岸：天气、资源和小型经济区域。
- 星骨遗迹：符文、回声和小头目区域。
- 月铃塔顶：终局首领和结局判定区域。

## 历史

旧守铃者曾经独自维持月铃，导致居民把记忆交给塔而不是彼此。失声事件不是单一敌人的破坏，而是山谷关系长期失衡后的结果。

## 魔法规则

1. 月铃只回应明确行动，不回应无来源的自由文本。
2. 绒火能修复物件，但不能凭空创造历史。
3. 传闻必须带来源、时间和失真程度。
4. 天气影响资源、敌人与对白，但不得随机阻断主线。
5. 结局由世界标记、关系和最终选择共同决定。
6. 居民记忆按存档隔离，不能跨存档串记忆。

## 阵营与物种关系

月铃山谷没有现实政治阵营。居民以手艺和承诺建立关系：守铃者、工坊、商摊、巡守、草药师、夜巡抄写员、桥匠和旅店形成互相依赖的小共同体。
