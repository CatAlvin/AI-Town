## 2. 产品定位

### 一句话体验

创建一座由 30 名独特兽人公民组成的活城镇。玩家既可以安静观看他们工作、交友、借债、犯罪、竞选，也可以像“上帝”一样输入一场灾难或奇迹，然后观察整个社会如何改变。

### 产品北极星

> 每一天都有因果，点开任何居民都有故事，输入一句话就能看见整个城镇产生真实变化。

### 设计判断

这是面向中文玩家的高可观赏性文明沙盒，不是传统 RPG，也不是数据后台。界面需要同时满足三件事：

1. 第一眼能看懂城里正在发生什么。
2. 继续看五分钟后，会对某些角色产生关心、偏爱或怀疑。
3. 输入一个世界事件后，能追踪它在数天内造成的连锁反应。

设计参数：

- `DESIGN_VARIANCE: 7`：地图和故事表达有个性，但核心操作位置稳定。
- `MOTION_INTENSITY: 6`：居民、关系和事件有流动感，所有动效都服务状态变化。
- `VISUAL_DENSITY: 7`：信息丰富但不堆满卡片，地图始终是视觉中心。

## 3. 当前版本审计

### 可继承资产

- 中文世界观、月铃山谷名称和暖色童话气质。
- 现有 8 名居民的物种、职业、轮廓和性格描述。
- Node.js 单命令启动、无数据库依赖、可离线降级的运行方式。
- 存档安全、密钥隔离、网络超时、配额和本地回退机制。
- Canvas 地图、音频合成、自动化测试和浏览器证据脚本。

### 必须替换的问题

- 自主模式只有 3 名角色，且按固定地点和固定剧情节拍循环。
- 角色没有财富、债务、职业生产、政治倾向、敌友网络等可持续状态。
- 事件只增加一句日志和一条记忆，未改变社会结构。
- 生命、体力、攻击等冒险 HUD 与文明观察玩法不匹配。
- 地图建筑是大面积低细节色块，角色共用简单人形，物种特征不够明显。
- Canvas 虽有设备像素比处理，但内部世界坐标、画布尺寸和 CSS 拉伸耦合，细节层级不足，视觉上仍显得模糊。
- 右侧长日志缺少主次、因果关系和角色筛选，很快会变成不可读的信息流。
- 当前 `public/app.js` 同时承担规则、状态、渲染、输入和音频，继续扩展会提高回归风险。

### 重构模式

采用“玩法与视觉完整重构，运行与安全基础保留”。旧世界观中的月铃、聚落和 8 名居民继续存在，但主体验改为 AI 文明模拟器。

## 4. 核心循环

1. **观察**：地图上的居民自主上班、购物、拜访、争吵、约会、借贷和竞选。
2. **追踪**：点击角色、建筑或事件，查看原因、记忆、关系和后续目标。
3. **干预**：在上帝输入框中输入自然语言事件，或从常用事件中一键选择。
4. **推演**：暂停、单日推进或切换 1x、2x、4x、8x 速度，观察影响扩散。
5. **复盘**：查看时间线、指标变化和关系图，找到“为什么会变成这样”。
6. **继续制造故事**：围绕已经形成的矛盾再次干预，让城镇产生新的历史。

默认进入游戏后城镇立即自主运行，不要求玩家先读教程或操作角色。首次提示只保留三个动作：点击居民、调节时间、输入上帝事件。

## 5. 首个可玩版本的硬性范围

- 30 名具名 AI 公民，每名都有职业、物种、外观轮廓、性格、财富、朋友、敌人、目标和记忆。
- 1 张完整城镇地图，至少包含 12 个有实际功能的建筑或公共地点。
- 每名公民至少 3 条初始记忆，总计不少于 90 条；短期记忆上限 20 条，旧记忆会压缩为人生摘要。
- 居民会依据时间、需求、性格、关系、财富和记忆自主选择行动。
- 至少覆盖经济、治安、关系、人口、政治五套相互影响的系统。
- 支持自然语言上帝事件，并提供本地规则降级。
- 支持社会关系图、居民详情、事件时间线和全城指标趋势。
- 支持暂停、单步、1x、2x、4x、8x、固定种子重开和自动存档。
- 开局后 10 个游戏日内必须自然出现至少 1 条可追踪的三段式故事链。
- 连续运行 100 个游戏日不崩溃，不出现 `NaN` 财富、悬空关系或不存在的角色引用。

### 公民数据模型

每个居民至少包含以下字段：

```text
identity      姓名、物种、年龄段、代词、立绘、地图形象
occupation    职业、技能、工作地点、工资、雇主或产业
personality   同理心、野心、诚实、冒险、纪律、社交六个维度
economy       现金、资产、债务、收入、消费偏好、库存
needs         饥饿、休息、安全、归属、成就
relationships 亲密、信任、敬畏、怨恨、债务和关系标签
goals         当前目标、长期目标、完成进度、阻碍条件
memories      事件、对象、情绪、可靠度、重要度、发生日
reputation    商业、道德、能力、政治四类声望
schedule      常规日程、临时计划、当前位置、移动目标
```

名字、物种、职业和核心人格为策划固定内容。数值、初始财富、关系强度和部分目标使用可复现种子生成，保证每局既熟悉又有变化。

## 7. 自主决策与记忆

### 决策方式

居民不逐帧调用大模型。每个模拟时段通过本地效用评分选择行动：

```text
行动分数 = 需求紧迫度 + 目标收益 + 性格偏好 + 关系影响
         + 记忆影响 + 环境机会 - 风险 - 时间与金钱成本
```

候选行动包括工作、经营、消费、借贷、偿债、拜访、帮助、送礼、争吵、约会、偷窃、举报、调查、竞选、投票、休息和迁居。

### 记忆方式

- 每条重要事件会写入参与者和目击者的记忆。
- 记忆包含来源和可靠度，传闻可能失真。
- 高重要度记忆会改变信任、目标、消费、投票和犯罪决策。
- 互相矛盾的记忆不会直接覆盖，而会降低确信程度。
- 超出短期上限的记忆会按主题压缩，例如“米露多次在危机中帮助我”。
- 角色详情可以解释某个行动引用了哪些记忆，避免“AI 为什么这么做”成为黑箱。

## 8. 社会系统

### 经济

- 职业生产商品或服务，建筑拥有库存、容量和所有者。
- 居民领取工资、消费、储蓄、借款、偿债、投资或破产。
- 价格由库存、需求、税率、事件和商人策略共同影响。
- 可创建新企业、雇佣员工、关店、合伙或垄断。
- 财富指标同时显示总财富、中位财富和不平等程度，避免平均数掩盖问题。

### 治安

- 犯罪由需求压力、性格、机会、怨恨、惩罚预期和记忆触发。
- 犯罪有受害者、目击者、证据、嫌疑、调查和裁决过程。
- 偷窃被发现后会改变财富、关系、声望、治安压力和政治议题。
- 治安官不会自动知道一切，错误指控也可能形成新的社会冲突。

### 关系

- 关系不是单一好感度，而是亲密、信任、敬畏、怨恨和债务五个维度。
- 一对居民可同时是朋友、债主和政治对手。
- 朋友会提供帮助，敌人会阻挠目标，债务会产生催收、宽限或报复事件。
- 社会关系图支持朋友、爱慕、敌对、债务、雇佣、亲属和政治影响七类边。

### 人口

- 开局有 30 名具名居民。
- 访客可因工作、治安、住房和政策成为移民；居民也可能离城。
- 第一版本人口变化以迁入和迁出为主，不引入婴儿成长与跨世代系统。
- 新移民由同一角色模板系统生成，必须具有物种轮廓、性格、职业诉求和至少一条来城原因。

### 政治

- 每 30 个游戏日举行一次市长选举，必要时可由危机提前触发。
- 候选人根据财富、声望、野心、关系网络和议题立场决定是否参选。
- 居民依据利益、信任、记忆和政策承诺投票。
- 市长可改变税率、治安预算、救济、矿权、贸易和移民政策。
- 政策必须落实到数值和行为，不做纯文本装饰。

## 9. 事件因果链

所有重要事件统一经过以下流程：

```text
触发原因 -> 参与者行动 -> 即时结果 -> 世界状态变化
         -> 关系与记忆写入 -> 新目标或后续事件 -> 时间线归档
```

示例链：

```text
第 1 日  焦麦开设面包店
第 8 日  雨季导致麦价上涨，焦麦向柳影借款
第 12 日 焦麦欠款 500，柳影开始催收
第 24 日 焦麦偷取市集面粉并被露爪目击
第 27 日 岩阵展开调查，米露选择为焦麦作证
第 35 日 薇萝凭借危机调解声望当选市长
```

时间线默认只突出改变两项以上系统的“故事事件”。普通吃饭、走路和工作仍会发生，但不会淹没玩家。

## 10. 上帝事件系统

### 玩家体验

地图底部始终显示一个短输入框，示例占位为“让这个世界发生一件事...”。输入后显示一句可读的影响摘要，玩家可立即施加，也可调整强度和持续时间。

常用事件提供快捷建议：

- 突然发生经济危机
- 城外发现黄金
- 连续七天下大雨
- 禁止私人借贷
- 举行提前选举
- 一位富商来到城里

支持撤销最近一次上帝事件，但不回滚该事件之后已经发生的所有自然历史。真正的历史回退通过存档快照完成。

### 技术流程

```text
中文输入
  -> 本地模板识别
  -> 无法识别时调用 DeepSeek
  -> 返回受限 JSON 事件计划
  -> Schema、范围和数值边界校验
  -> 展示影响摘要
  -> 写入世界事件队列
  -> 由确定性模拟器执行
```

DeepSeek 只负责两类工作：

1. 把自然语言转换成安全、有限的结构化事件。
2. 为已经发生的关键事件生成更自然的中文标题、对话和摘要。

DeepSeek 不直接修改存档，不决定财富结算，不凭空创建不存在的角色 ID。未配置密钥、超时、限额或响应无效时，系统自动使用本地模板和本地叙事，不停止模拟。

### 两个基准事件

**经济危机**应逐步造成：企业收入下降、失业或降薪、消费收缩、债务违约上升、治安压力增加、朋友间互助或冲突增多、救济政策成为选举议题、部分居民迁出。

**发现黄金**应逐步造成：矿业岗位和迁入增加、物价和地价上涨、财富快速增长但差距扩大、矿权竞争、偷窃与走私风险上升、商人和工人形成不同政治诉求、部分旧关系因利益重新排列。

## 11. 地图与交互设计

### 桌面主界面

```text
┌ 城镇名 / 第 18 日 ── 人口 财富 治安 关系 政治 ── 暂停 1x 2x 4x 8x ┐
├──────────────────────────────────────┬─────────────────────┤
│                                      │ 今日大事            │
│          高清可缩放城镇地图          │ 关键事件时间线      │
│    居民移动、对话、工作和冲突可见    │ 角色关注列表        │
│                                      │ 影响中的世界事件    │
├──────────────────────────────────────┴─────────────────────┤
│ 让这个世界发生一件事...                         [施加事件] │
└────────────────────────────────────────────────────────────┘
```

### 关键交互

- 单击居民：打开人物抽屉，显示职业、财富、情绪、目标、最近记忆和关键关系。
- 双击居民：镜头跟随，并将与该居民相关的事件置顶。
- 单击建筑：查看所有者、雇员、库存、价格、收入和当前事件。
- 单击事件：高亮参与者、地点、前因、后果以及受影响指标。
- 关系图：可按关系类型筛选，悬停边显示形成原因，单击节点回到地图人物。
- 指标：显示当前值和最近 30 日趋势，点击后过滤导致变化的事件。
- 快捷键：空格暂停，句点推进一天，数字键切换速度，`F` 跟随选中居民，`Esc` 关闭抽屉。

### 移动端

- 地图占据首屏主体，顶部只保留日期、速度和暂停。
- 指标改为横向滑动条，事件流和人物详情使用底部抽屉。
- 上帝输入固定在底部安全区域，打开键盘时地图自动缩小而不被遮挡。
- 所有功能可通过触控完成，不依赖悬停和键盘。

## 12. 高清美术方向

### 视觉主题

采用“月光微缩城镇沙盘”方向：冷灰月光界面、清澈的自然地貌、墨绿植被、河水蓝和单一绒火红交互强调色。避免羊皮纸加棕色的单调暖色方案，也不使用通用 AI 紫色发光。

### 角色表现

- 30 名首发居民各有独立轮廓，不再共用“圆头加两只耳朵”的身体模板。
- 物种差异必须体现在头型、耳朵、角、尾巴、羽毛、体型、步态和待机动作中。
- 地图角色使用 4 个朝向、行走、工作、交谈、争吵、庆祝、低落至少 7 组状态。
- 人物抽屉使用 384x384 以上高清半身像，地图角色使用 2x 或 4x 源素材。
- 服装直接传达职业与财富变化，例如破旧围裙、行会徽记、市长披肩和债务查封标记。

### 地图表现

- 建筑拥有独立剪影和功能动画，例如面包店烟囱、银行开门、警署巡逻灯、矿场升降架。
- 道路、草地、河岸和屋顶使用分层纹理，不用大面积纯色色块。
- 季节、天气、时段只改变同一视觉主题内的光照和材质，不切换成另一套 UI 主题。
- 事件在地图上留下短期可见痕迹，例如排队、封条、庆祝旗、破窗、施工围栏和竞选海报。

### 清晰度技术标准

- Canvas backing store 使用实际 CSS 尺寸乘 `devicePixelRatio`，上限根据性能动态设为 2 或 3。
- 渲染前统一 `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)`，世界坐标与物理像素解耦。
- 地图相机只在逻辑坐标中缩放，不再用 CSS 强行拉伸低分辨率画布。
- 所有位图素材提供 2x 或 4x 版本，并固定宽高比，避免浏览器二次模糊缩放。
- 文字、关系线和 UI 图标优先使用 DOM 或 SVG 层，避免 Canvas 小字号文字发虚。
- 1920x1080、2560x1440、4K、1280x720 和 390x844 均需截图验收。

### UI 规范

- 选用一套无衬线中文字体栈，数字使用等宽字形，避免过大的标题。
- 面板圆角统一为 8px，按钮使用图标加简短标签，纯图标按钮提供中文提示。
- 地图、时间线、人物抽屉和关系图不互相套卡片，使用分栏、留白和细分隔线建立层级。
- 绒火红只用于可点击重点与当前选中状态。关系类型和指标允许使用有文字或图标辅助的语义色。
- 所有文本和控件达到 WCAG AA 对比度，不能只用颜色表达敌友或涨跌。
- 自动动画尊重 `prefers-reduced-motion`，关闭后保留瞬时状态反馈。

## 13. 技术架构

### 总体策略

保留现有 Node.js 服务、静态资源服务、安全边界和单命令启动。前端继续使用浏览器原生 ES Modules，以最少依赖完成第一版，但把当前单文件应用拆成明确模块。关系图优先使用 SVG，地图继续使用 Canvas 2D。

```text
src/civilization/
  constants.js          数值边界、时间与系统常量
  cast.js               30 名固定角色定义与生成规则
  worldFactory.js       种子世界创建与存档迁移
  simulation.js         时钟、行动选择与事件队列
  economy.js            工作、企业、价格、财富和债务
  relationships.js      多维关系、传播与社会网络
  crime.js              犯罪、目击、证据、调查和裁决
  politics.js           议题、政策、竞选和投票
  population.js         迁入、迁出、住房和岗位
  memories.js           记忆写入、衰减、摘要和引用
  godEvents.js          本地事件解析、校验和执行
  story.js              因果链聚合与重要事件筛选

public/modules/
  app.js                 启动与页面级协调
  store.js               UI 状态与模拟快照
  mapRenderer.js         高 DPI 地图和角色渲染
  camera.js              平移、缩放、跟随和坐标转换
  characterArt.js        角色轮廓、动画和素材映射
  timelineView.js        事件时间线和筛选
  citizenDrawer.js       居民详情
  relationshipGraph.js  SVG 社会关系图
  godEventComposer.js    上帝输入、预览和错误状态
  audio.js               环境声与事件反馈
```

### 模拟与渲染分离

- 模拟器按固定逻辑步长运行，速度变化只改变每秒执行的逻辑步数。
- 渲染使用 `requestAnimationFrame` 并在两个模拟状态之间插值。
- 30 名居民的决策按时段执行，不在每一帧重新计算。
- UI 只订阅已变化的切片，避免每次移动都重绘全部面板。
- 随机数统一使用可复现 PRNG，存档记录种子和事件序号。

### 存档

- 存档 schema 升级到版本 3，保留旧存档导入并标记为“经典冒险存档”。
- 文明存档保存世界种子、日期、公民状态、关系、记忆摘要、企业、政策和事件时间线。
- 每 5 个游戏日建立轻量快照，保留最近 20 个快照。
- 提供导出、导入、重命名和从某日创建分支世界。

### 服务端接口

- `POST /api/civilization/interpret-event`：把中文上帝输入转换为受限事件 JSON。
- `POST /api/civilization/narrate`：批量润色已发生的关键事件与对话。
- `GET /api/status`：继续提供 LLM 是否可用和版本信息。
- 所有接口复用请求大小、速率、会话配额、超时、日志脱敏和本地回退机制。
- API Key 只从服务端环境变量读取，永不进入浏览器代码、存档或日志。

## 15. 玩法节奏与“连续玩几十分钟”的保障

- 每 10-20 秒出现一条轻量可见互动，但不全部写入大事件时间线。
- 每 1-3 个游戏日形成一条值得阅读的关键事件。
- 每 7-12 个游戏日形成一次跨系统转折，例如破产、告发、结盟、开店或政策冲突。
- 每 30 个游戏日产生一次政治结算和城市阶段总结。
- 同一事件模板连续 12 个游戏日内不重复作为主事件。
- 每条重大故事至少牵涉 2 名角色和 2 套系统。
- 玩家关注某人后，系统优先展示与其有关的前因和后果，但不偏改模拟结果。
- “意外”来自性格、关系和环境组合，不来自无原因的随机反转。

## 18. 完成定义

重构完成不是“屏幕上有 30 个移动图标”，而是满足以下结果：

- 焦麦开面包店后，原料、工资、债务、竞争和关系都真实存在。
- 某人偷东西被发现后，目击、调查、声望、敌友和选举会继续受影响。
- 某人成为市长时，玩家可以沿时间线看见这件事如何一步步发生。
- 玩家输入“发生经济危机”或“发现黄金”后，人口、财富、治安、关系和政治都会以不同速度改变。
- 即使完全不使用 DeepSeek，小镇仍能自主运行、产生因果故事并安全存档。
- 画面在高分辨率屏幕上清晰、细腻、有独特兽人轮廓，让玩家愿意继续看下去。
