# 美术圣经

## 镜头与比例

- 2D 俯视角，角色约 44–70 像素高，建筑与地标保持 2–4 倍角色高度。
- Canvas 图形使用软边矩形、椭圆、手绘感色块和少量发光，不使用写实照片。

## 色板

- 主色：苔谷绿 `#8ab77f`、绒火红 `#c95a3e`、月铃金 `#f1de87`
- 辅色：月铁蓝灰 `#7d879a`、河岸蓝 `#5fa8c7`、星骨紫 `#6a5a92`
- UI：羊皮纸底 `#fff8e8`、墨色 `#211f28`、边线 `#d4c2a4`

## 角色

- 绒火：赤狐与小熊猫混血，短斗篷、大耳、环尾、月铃木杖。
- NPC 用物种轮廓区分：狐、獾、兔、狼、鹿、鸮、松鼠、山羊。
- 身体语言：耳朵表达警觉，尾巴表达紧张或信任，物种习惯进入对白。

## UI 材质

界面采用羊皮纸、木牌和铜铃感，不使用默认浏览器按钮风格。按钮半径不超过 8px，信息面板保持可扫读。

## 禁用风格

- 不使用占位图、默认灰按钮、暗黑科幻 UI、霓虹赛博、写实恐怖。
- 不使用未经授权的外部图片、字体、音乐或音效。
