# 资产许可清单

当前版本不包含未经记录的外部素材文件。

| 类型 | 来源 | 许可/权利 | 说明 |
|---|---|---|---|
| 代码 | 本项目自制 | 项目私有 | 无第三方运行时依赖。 |
| Canvas 角色与场景 | 本项目自制 | 项目私有 | 由 `public/app.js` 程序化绘制。 |
| UI 样式 | 本项目自制 | 项目私有 | 由 `public/styles.css` 编写。 |
| AI 文明高清地图 | OpenAI ImageGen 按项目提示生成 | 用户项目内使用 | 文件为 `public/assets/civilization/town-map.png`，无第三方商标、文字或水印。 |
| AI 文明角色与动效 | 本项目自制 | 项目私有 | 由 `public/civilization.js` 按兽人种族特征程序化绘制。 |
| AI 文明 UI 样式 | 本项目自制 | 项目私有 | 由 `public/civilization.css` 编写。 |
| 音乐与音效 | 本项目自制 | 项目私有 | Web Audio 按场景和操作实时合成，无外部音频文件。 |
| 中文文本/设定 | 本项目自制 | 项目私有 | 见 `src/gameData.js` 与文档。 |

如后续引入外部素材，必须在进入正式资源目录前记录原始来源、许可、署名要求和下载时间。
