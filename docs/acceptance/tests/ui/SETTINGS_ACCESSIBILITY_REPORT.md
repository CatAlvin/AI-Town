# 设置与可访问性报告

生成时间：2026-09-02T20:43:15.841Z

## 结论

- 设置入口覆盖主音量、音乐、音效、静音、文字速度、亮度、屏幕震动、降低动态效果、难度、文字缩放和全屏。
- 音频设置覆盖主音量、音乐音量、音效音量和一键静音。
- 设置使用独立键 `moonbell.settings` 持久化，不依赖单个游戏存档槽。
- 难度在战斗伤害和移动速度中生效；文字缩放影响界面提示字号。
