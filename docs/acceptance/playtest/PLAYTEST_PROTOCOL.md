# 外部试玩协议

目标验收：`QA-06`、`QA-07`、`PROD-02`、`UX-02`

## 样本要求

- 至少 5 名非开发者。
- 至少 2 名轻度游戏玩家、2 名有动作/冒险游戏经验玩家、1 名很少玩游戏的用户。
- 测试者不提前阅读攻略，不接受口头提示。

## 测试环境

- 浏览器：桌面 Chromium 或 Firefox。
- 地址：正式候选版本 URL 或本地等价构建。
- 输入：键盘。
- 录屏：允许只录屏幕，不录人脸。

## 任务

1. 从首页判断作品类型，并开始游戏。
2. 在无口头指导下完成教学目标：移动、交互、任务查看、攻击/闪避、保存。
3. 尝试完成至少一个跨区任务。
4. 至少 3 名测试者观看完整通关或亲自完成主线。
5. 结束后填写开放反馈。

## 通过线

- 至少 4/5 人能无口头指导完成教学。
- 至少 3/5 人完成主线或观看完整通关。
- 被 2 名以上玩家重复指出的 P0/P1 理解或操作问题必须修复，或在 `PLAYTEST_ISSUE_CLOSURE.md` 中给出明确拒绝理由。

## 观察重点

- 是否知道当前目标在哪里。
- 是否能理解交互提示和任务日志。
- 是否能在战斗失败后重试。
- 是否注意到保存状态。
- 是否能说出至少一个喜欢的角色、场景或系统变化。
